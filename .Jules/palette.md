## 2025-10-02 - Tablist ARIA Accessibility in Workspace Navigation
**Learning:** Icon buttons and tab navigation bars in ProposalCartWorkspace require explicit `aria-label`, `role="tablist"`, `role="tab"`, and `aria-selected` attributes for optimal screen reader navigation.
**Action:** Always include semantic tab roles and dynamic item-specific ARIA labels when building sub-navigation tab bars or icon action buttons.
