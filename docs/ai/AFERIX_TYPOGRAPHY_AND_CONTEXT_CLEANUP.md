# AFERIX — Typography and Context Cleanup

## Goal
Refine the visual system and reduce redundant context in Aferix.

Current phase:
visual cleanup, typography consolidation and cognitive noise reduction.

Do not add new features.
Do not change business rules.
Do not change the functional flow.
Focus only on refinement, consistency and premium mobile-first UX.

## 1. Typography consolidation

Problem:
Some screens use different visual weights, scales and typography behavior.

Result:
The application feels visually inconsistent.

Goal:
Consolidate one premium typography system.

Standardize:
- titles
- subtitles
- labels
- metrics
- buttons
- helper text
- card text

Ensure:
- same visual family
- same hierarchy
- same visual weight
- same mobile readability

The application must feel like one cohesive product.

## 2. Remove redundant context

Problem:
The system repeats context too much.

Example:
Novo orcamento appears across internal steps of the budget flow.

This creates:
- visual noise
- redundancy
- cognitive load
- inflated interface feeling

Goal:
Apply functional minimalism.

Rule:
Context should appear only where it helps orientation.

After the user enters the budget flow, do not repeat:
- Novo orcamento
- intent already implied
- context already communicated by the stepper

The steps already communicate the flow:
- Cliente
- Servico
- Itens
- Custos
- Revisao
- Documento/PDF

## 3. Interface cleanup

Reduce:
- repeated titles
- redundant labels
- excessive headers
- unnecessary contextual text

The layout should breathe more.

## 4. Novo Fechamento button

Problem:
The current button:
- is too narrow
- breaks text
- has inadequate width
- does not match the premium card style

Fix:
- adequate minimum width
- prevent text wrapping
- improve padding
- improve alignment
- improve proportions
- integrate with premium design system

The CTA should feel strong, clear and premium.

## 5. Final experience

Aferix should communicate:
- clarity
- flow
- visual intelligence
- sophistication
- comfort
- consistency

The user should never feel:
- excessive information
- repeated context
- unnecessary titles
- inflated UI

## 6. Rules

Do not:
- change business rules
- create new features
- change functional flow
- add unnecessary visual elements

Do:
- clean
- reduce
- consolidate
- standardize
- refine
- preserve dark premium mobile-first identity
