# AFERIX FIELD HARDENING AUDIT
**STATUS:** APPROVED
**PERSPECTIVE:** "Técnico em cima de uma escada."

- **Com uma mão?** Sim. Scroll vertical apenas, botão `[ CONTINUAR EXECUÇÃO ]` ocupa a tela inteira embaixo.
- **Com luva?** Sim. Botões possuem hit-areas invisíveis maiores que 56x56.
- **No sol?** Sim. Auto-contraste nas fontes primárias `text-white` sobre `bg-surface-900`.
- **Sem internet?** Sim. O Dexie v26 resolve tudo localmente; o PWA retém os Eventos `operationalEvent`.
- **Sem teclado?** Sim. Checklists são cliques (`[ MARCAR TUDO OK ]`). Anomalias possuem o botão `Gravar Áudio` e `Tirar Foto` como prioritários.
- **Auto Save:** Implementado nativamente. Zero botões de "Salvar".
