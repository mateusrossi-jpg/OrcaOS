# AFERIX — DESIGN SYSTEM CONSTITUTION

**STATUS: FROZEN | RATIFIED | SUPREME VISUAL AUTHORITY**
**VERSION: 1.0**

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PURPOSE
This document defines the permanent visual language of Aferix. Its objective is to guarantee that every screen, card, component, interaction, and module feels like the same product. No screen may create its own visual language. No component may invent its own rules. **Consistency outranks creativity.**

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 1 — DESIGN PHILOSOPHY
Aferix is a **PREMIUM TECHNICAL OPERATING SYSTEM**.
The visual experience must feel: **Professional, Precise, Reliable, Expensive, Fast, and Technical.**
The user must feel: *“I am operating a professional company,”* not *“I am filling forms.”*

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 2 — VISUAL IDENTITY (DARK PREMIUM)
Color exists to communicate priority, never for decoration.

*   **Primary Background:** Near Black / Graphite
*   **Card Background:** Elevated Graphite Surface
*   **Primary Accent:** Aferix Gold
*   **Secondary Accent:** Technical Cyan
*   **Success:** Green | **Warning:** Amber | **Danger:** Red | **Neutral:** Grey Scale

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 3 — TYPOGRAPHY HIERARCHY
1. **Level 1:** Revenue Totals (Largest)
2. **Level 2:** Page Titles
3. **Level 3:** Card Titles
4. **Level 4:** Entity Information
5. **Level 5:** Supporting Information
6. **Level 6:** Metadata (Smallest)

**Rule:** Revenue numbers must always dominate. Metadata must never compete for attention.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 4 — SPACING SYSTEM
Single spacing scale only: **XS, S, M, L, XL, XXL.**
All layouts derive from this scale. No manual pixel adjustments. Consistency outranks density.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 5 — CARD SYSTEM
Only three card classes exist:
*   **TYPE A (Attention):** Maximum weight. Immediate action (Blocked WO, Overdue Payment).
*   **TYPE B (Operational):** Medium weight. Execution (Proposal, Client, Work Order).
*   **TYPE C (Information):** Minimal weight. Awareness (KPIs, Monthly Revenue).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 6 — BORDER RADIUS & ELEVATION
*   **Radius:** Small, Medium, Large. No custom values.
*   **Elevation:** Level 0 (Surface), Level 1 (Card), Level 2 (Attention), Level 3 (Modal/Sheet).
Elevation communicates priority. No decorative shadows.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 7 — BUTTON SYSTEM
Only **ONE Primary Button (P0)** per screen.
*   **P0:** Primary Action (Thumb reachable).
*   **P1:** Secondary Action.
*   **P2:** Utility Action.
**Rule:** Two primary actions are strictly forbidden.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 8 — INPUT & NAVIGATION COMPONENTS
*   **Inputs:** Large touch targets, high contrast, numeric keyboard preference, voice input encouraged.
*   **Bottom Sheet:** Fast selection (Clients, Templates).
*   **Side Drawer:** Navigation.
*   **Modal:** Critical confirmation only. *Never use a modal when a sheet solves the problem.*

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 9 — STATES (OFFLINE, LOADING, EMPTY, ERROR)
*   **Offline:** Normal state. Never block work. Local operation is primary.
*   **Loading:** Skeletons preferred. Home must never wait for network.
*   **Empty:** Must explain cause, why it's empty, and next action (with one button).
*   **Error:** Explain cause, consequence, and recovery. No technical jargon.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PART 10 — CONSTITUTIONAL LAWS
1.  **LAW #01:** Revenue visibility outranks aesthetics.
2.  **LAW #02:** Consistency outranks originality.
3.  **LAW #03:** Attention outranks information.
4.  **LAW #04:** One primary action per screen.
5.  **LAW #05:** Cards are the universal language.
6.  **LAW #06:** Offline operation is normal.
7.  **LAW #07:** Visual hierarchy must reflect business priority.
8.  **LAW #08:** The interface adapts to the technician; the technician never adapts to the interface.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## FINAL DESIGN TRUTH
The purpose of the Aferix Design System is not beauty; it is **reducing cognitive load**. Every visual decision must increase Speed, Confidence, Clarity, Revenue, and Execution. Anything else is noise.
