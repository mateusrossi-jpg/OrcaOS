# AFERIX SPACING LAWS — THE RHYTHM
**Status: MANDATORY | Focus: OPERATIONAL BREATHING ROOM**

## 1. O GRID DE BASE
Tudo no Aferix é construído em múltiplos de `4` e `8`.
- **XS:** `4px`
- **SM:** `8px`
- **MD:** `16px` (Margem padrão mobile)
- **LG:** `24px`
- **XL:** `32px`

## 2. REGRAS DE DISTÂNCIA
- **Entre Seções:** `48px` (`var(--spacing-section)`).
- **Entre Cards:** `24px` (`var(--spacing-card)`).
- **Interno de Card:** `24px` no mínimo.
- **Header para Conteúdo:** `32px` a `40px`.

## 3. COMPENSAÇÃO DE HIERARQUIA
- Use espaçamentos maiores para sugerir novos blocos lógicos.
- Use espaçamentos menores (`8px` ou `12px`) para agrupar Label e Input.

## 4. PROIBIÇÕES
- ❌ **Paddings de 1px ou 2px:** Cria uma sensação de ruído/falha de design.
- ❌ **Conteúdo colado na borda:** Pelo menos `16px` de distância das laterais físicas da tela.
- ❌ **Interfaces compactas:** O Aferix é premium; ele tem orgulho do seu espaço vazio.
