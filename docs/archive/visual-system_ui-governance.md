# AFERIX UI GOVERNANCE — THE CONSTITUTION
**Status: MANDATORY | Target: EXECUTIVE OS V5**

## 1. THE SUPREME RULE
> "Se um elemento parece um dashboard, ele está errado."

O Aferix não é uma coleção de páginas; é um **Sistema Operacional Proprietário**. Ele deve parecer "caro", silencioso e altamente funcional.

## 2. MINDSET EXECUTIVO VS. ADMIN PANEL
| Dashboard Tradicional (ERRO) | Executive OS (AFERIX) |
|:---|:---|
| Grids densos e tabelas infinitas | Espaçamento generoso e foco editorial |
| Bordas pretas e outlines fortes | Camadas de grafite e profundidade atmosférica |
| Cores neon e contrastes agressivos | Tons terrosos, Gold restrito e luz suave |
| Micro-ícones em todo lugar | Ícones cinematográficos com alta opacidade |
| Botões Android/Web padrão | Botões táteis com 16px+ de raio |

## 3. MANDATOS DE COMPOSIÇÃO
- **Silêncio Visual:** Reduza a densidade de informação até sobrar apenas o essencial.
- **Cinematic Atmosphere:** Cada tela deve ter profundidade. Use o gradiente de base e a vinheta oficial.
- **Human Centered:** Interfaces feitas para dedos reais em telas reais (Mobile-First Absoluto).

## 4. CHECKLIST DE NOVA TELA
Antes de considerar uma tela "concluída", ela deve passar por este escrutínio:
1. [ ] A tela utiliza o `PageShell` oficial?
2. [ ] Existe um herói visual (Primary Data)?
3. [ ] O espaçamento entre seções é de 48px?
4. [ ] Todos os cards têm radius de 24px?
5. [ ] Existe algum preto puro (#000) ou branco puro (#FFF)? (Se sim, CORRIJA).
6. [ ] A tela parece "cara" ou parece um template Bootstrap?

## 5. REVISÃO DE PROJETO
Qualquer PR que introduzir estilos inline, cores hexadecimais aleatórias ou border-radius menores que 16px deve ser **REJEITADO IMEDIATAMENTE**.
