# AFERIX HOME V3.3 — OFFICIAL REFERENCE

Status: DESIGN FREEZE
Version: V3.3
Date: 2026-06-04

---

## Purpose

The Home screen is the operational command center of Aferix SOLO.

Its purpose is NOT financial analysis.

Its purpose is NOT reporting.

Its purpose is NOT administration.

The Home exists to answer:

1. What is my next service?
2. Where do I need to go?
3. What requires attention?
4. What action should I execute now?

The user must understand the screen within 3 seconds.

---

# Core Principles

- Mobile First
- Field First
- Action First
- Low Cognitive Load
- One-Hand Usage
- Outdoor Visibility
- Revenue Through Execution
- No Dashboard Syndrome

---

# Official Information Hierarchy

## 1. Header

Displays:

- Greeting
- Daily context
- Number of appointments
- Time until next service

Example:

Bom dia, Mateus.
3 atendimentos agendados hoje.
O próximo é em 45 min.

---

## 2. Next Service Hero

Primary block.

Must always be visible above the fold.

Contains:

- Service name
- Client name
- Time
- Route information
- WhatsApp shortcut
- Phone shortcut
- Start Route CTA

Primary action:

INICIAR ROTA

This is the most important action on the Home screen.

---

## 3. Today's Agenda

Compact timeline.

Purpose:

Provide awareness.

Not detailed planning.

Displays:

- Completed services
- Current service
- Upcoming services

Must remain compact.

Must not compete with the Hero.

---

## 4. Quick Actions

Purpose:

Reduce friction.

Official actions:

- Nova Proposta
- Novo Cliente
- Serviço Expresso
- Receber Pagamento

Priority:

Nova Proposta

May receive visual emphasis.

---

## 5. Requires Attention

Purpose:

Expose operational backlog.

Examples:

- Cliente aguardando retorno
- OS pausada
- Proposta sem resposta

Rules:

- Human language only
- No technical jargon
- No system terminology

---

## 6. Bottom Navigation

Current structure:

- Home
- Operações
- Financeiro
- Agenda
- Mais

Future review required:

Clarify distinction between Operações and Agenda.

# Forbidden Elements

The following items do NOT belong to Home:

- Revenue dashboards
- Cash flow reports
- Financial charts
- LTV metrics
- Complex KPIs
- Administrative statistics
- CRM dashboards

These belong to Finance and specialized modules.
