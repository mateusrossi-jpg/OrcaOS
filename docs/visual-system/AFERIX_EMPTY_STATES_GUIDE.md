# AFERIX EMPTY STATES GUIDE
**STATUS:** ACTIVE

**Proibido:** "Não há dados", "Zero resultados", ou tela cinza e morta.

**Padrões Oficiais de Estados Vazios Humanizados:**
1. **Agenda do Técnico:**
   "Sua rota está livre no momento. Quando o coordenador despachar um serviço, ele aparecerá aqui."
2. **Revenue Inbox (Comercial):**
   "Você não tem anomalias novas para orçar hoje. Que tal revisar as propostas enviadas na semana passada?"
3. **Dispatch Board (Gestor):**
   "Tudo tranquilo. Não há incêndios ou urgências precisando do seu resgate."
4. **Client Portal (Propostas):**
   "Você está em dia! Não há nenhum orçamento aguardando sua revisão financeira."

*Toda tela vazia deve confortar o usuário ou direcioná-lo para a próxima melhor ação.*
