# AFERIX VISUAL PROTOCOL

The images inside /lovable/referencias are the primary visual source of truth.

Do not use generic SaaS references.

Do not use generic ERP references.

Do not invent new visual patterns.

Every UI decision must converge toward the visual language shown in the reference images.

The goal is not similarity.

The goal is visual convergence.

---

## Core Identity

Aferix is not an ERP.

Aferix is an Executive Operating System.

The user must feel:

"I am operating my company."

Never:

"I am filling forms."

---

## Visual Principles

Premium.

Calm.

Operational.

Executive.

Cinematic.

Dense but breathable.

High trust.

High authority.

---

## Material System

Use:

- large rounded surfaces
- subtle borders
- dark graphite materials
- layered depth
- restrained glow
- premium spacing

Avoid:

- flat dashboards
- card grids
- enterprise ERP appearance
- CRUD feeling
- spreadsheet feeling

---

## Typography

Large authority numbers.

Large authority titles.

Small uppercase labels.

Strong hierarchy.

Never use equal visual weight.

---

## Navigation

Navigation must feel like an OS.

Not like pages.

Not like menus.

Not like modules.

All screens belong to the same environment.

---

## Screen Construction

P0 = Hero Information

P1 = Operational Context

P2 = Active Objects

P3 = Supporting Data

Every screen must follow this hierarchy.

---

## Convergence Rule

When uncertain:

Copy the behavior shown in the reference images.

Do not invent.

Converge.
