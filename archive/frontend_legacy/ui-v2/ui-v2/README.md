# UI‑V2 Layer

This directory will host the **next‑generation visual layer** for Aferix. All new, neutral‑styled components will be placed here, leaving the existing `src/ui/` untouched.

* No functional code will be changed.
* The purpose is to allow side‑by‑side comparison with the legacy UI.
* Once completed, the Home screen will be migrated to this layer as a pilot.
